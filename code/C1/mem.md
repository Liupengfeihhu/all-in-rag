

RAG 分块实验总结
1. Chunk Size（分块大小）
- 大 Chunk：单个块包含的信息多，较小的 Top-K 就可能覆盖更多内容，但容易引入无关信息，增加 Token 消耗，也可能降低检索的精准度。
- 小 Chunk：信息粒度更细，检索可能更精准，但容易丢失上下文，需要更大的 Top-K 才能覆盖完整信息。
2. Top-K（检索数量）
- K 越大，通常能覆盖更多信息，但也会增加无关内容、重复内容和 LLM 的 Token 消耗。
- K 越小，检索结果更精简，但可能遗漏重要信息。
- 注意：小 Chunk + 大 K 不一定等价于大 Chunk + 小 K，因为检索到的信息及其上下文可能不同。
3. Chunk Overlap（重叠大小）
- Overlap 过小：可能导致句子或语义在 Chunk 边界处被截断，上下文不完整。
- Overlap 过大：产生更多重复信息，可能使 Top-K 被相似 Chunk 占据，降低有效信息覆盖率。
- 合理的 Overlap 可以减少边界信息丢失，但不保证提高检索效果。
